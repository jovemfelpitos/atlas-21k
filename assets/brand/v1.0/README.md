# Atlas Run — Brand Assets V1.0

**Status:** símbolo vetorial aprovado visualmente pelo proprietário; pacote técnico preparado para revisão antes da integração.

## Conteúdo
- `svg/simbolo/`: símbolo reconstruído com caminhos SVG reais, colorido, branco e preto. Mantém os mesmos paths do pacote preliminar aprovado.
- `svg/logotipo/`: composições horizontal e vertical com símbolo e texto editável. **A composição tipográfica é uma aproximação técnica**, não um contorno tipográfico original da prancha.
- `png/`: exportações transparentes de símbolo e logotipo.
- `icons/`: ícones PWA, PNGs e favicon.
- `ATLAS_RUN_PREVIEW_V1.0.png`: prancha de conferência.

## Identidade
- Base: `#0B1117`; energia: `#C9FF60`; texto: `#F3F6F9`; apoio: `#AFC2D1`.
- Fonte prevista no guia: **Sora**. Os SVGs de logotipo utilizam texto com `font-family: Sora, DejaVu Sans, sans-serif`. **A fonte Sora deve estar instalada/carregada no destino**. Os PNGs exportados neste ambiente podem usar fonte substituta; por isso, **não considere os lockups com texto aprovados definitivamente sem conferência tipográfica**.
- Assinatura: **Seu plano. Seu ritmo.**

## Integração
1. Usar primeiro os SVGs do símbolo e o ícone escuro para protótipos.
2. Validar visualmente o wordmark com a fonte Sora real antes de publicação.
3. Não alterar geometria do símbolo sem aprovação.
4. Evitar cores monocromáticas sobre fundos sem contraste.
5. SVGs são vetoriais reais; PNGs são rasterizados.

## Limitações honestas
O monograma foi reconstruído de PNG, não de arquivo vetorial original de designer. A aprovação é visual, não prova igualdade geométrica exata. As composições tipográficas e dimensões mínimas devem ser homologadas no layout real.
